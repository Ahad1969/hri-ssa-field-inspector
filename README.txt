HRI SSA FIELD INSPECTOR — VERSION 1.4 PILOT
===========================================

UPGRADE FROM THE ANDROID VERSION 1.3
1. Open the currently installed Android app. Download a FULL JSON BACKUP and save a second copy outside the phone before upgrading.
2. Upload ONLY these seven program files to the existing GitHub repository root, replacing prior versions. NEVER upload survey backup JSON, photos or voice notes to public GitHub.
3. GitHub Pages automatically publishes the updated files. Refresh the app after deployment (or fully close/reopen) and check footer Version 1.4 pilot.
4. Check existing site surveys, issues, photos and voice notes BEFORE creating new records. Do NOT uninstall the PWA or clear site data.
5. Test the new evidence export and verify its files. Continue making FULL JSON backups daily.

NEW IN VERSION 1.4
- Backup / Export > Download all evidence ZIP. Works offline; file folders grouped by Site ID / Issue ID (or Unlinked).
- ZIP contains JPG photographs, original-format saved voice audio (usually WebM), Evidence_Register.csv with associations and transcripts, and a README.
- Backup / Export > Download evidence register CSV.
- Review tab > Export site evidence ZIP for the active site only.
- Photo tab > Download JPG per photograph; Voice tab > Download audio per recording.
- Standard ZIP STORE implementation, no external libraries or uploads. Large exports >200 MB require site-by-site ZIP exports.
- All original survey storage schema, existing data, issue links, and the Full JSON backup/restore feature are unchanged.

IMPORTANT
Evidence ZIP is a report-preparation deliverable, NOT a replacement for the Full JSON backup. It cannot be restored into the app. The full JSON backup includes the editable records and is needed for recovery. ZIP contains potentially confidential evidence; store and share only through approved channels.
